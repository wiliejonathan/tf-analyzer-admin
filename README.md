# TF Analyzer Analyst — License Admin (REV300)

## Isi paket
- `index.html`
- `styles.css`
- `app.js`
- `config.js`
- `assets/`

## Cara publish di GitHub Pages
1. Extract ZIP.
2. Upload semua isi folder `github-pages` ke root repository GitHub Pages.
3. Pastikan file `index.html` berada di root.
4. Buka `config.js` jika ingin hardcode Apps Script `/exec` URL.
5. Kalau `config.js` kosong, URL `/exec` tetap bisa diisi langsung di halaman login.

## Fitur utama
- UI modern & responsive (desktop, tablet, mobile)
- Search + highlight
- Tambah user + tampilkan token
- Status dot PC & Mobile
- Reset PC / Reset Mobile
- SEND EMAIL / SEND EMAIL UPDATE
- SEND EMAIL ALL / SEND EMAIL ALL UPDATE
- Auto-refresh background tiap 30 detik
- Tombol refresh manual dihapus sesuai permintaan
